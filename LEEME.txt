AGRIMTOP — DEMO WEB | ENMY DIGITAL STUDIO
=========================================

Archivos:
- index.html: página web
- styles.css: diseño y adaptación a celulares
- script.js: menú y formulario de cotización por WhatsApp
- assets/: logo oficial y dos fotos originales optimizadas

CÓMO VERLA:
1. Extrae la carpeta del ZIP.
2. Abre index.html en Chrome/Edge, o en VS Code usa Live Server.
3. Prueba el menú desde el celular y el formulario.

CÓMO PUBLICAR EN GITHUB PAGES:
1. Crea un repositorio público llamado agrimtop-demo.
2. Sube index.html, styles.css, script.js y la carpeta assets (sin cambiar la estructura).
3. Ve a Settings > Pages > Build and deployment > Deploy from a branch.
4. Elige main y /(root), guarda y espera la publicación.
5. Normalmente quedará en https://enmydigitalstudio.github.io/agrimtop-demo/
   (confirmar siempre la URL exacta que GitHub muestre).
